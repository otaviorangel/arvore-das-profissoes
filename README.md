🌳 Árvore Genealógica do Otávio

Este repositório apresenta a árvore genealógica da minha família, destacando os integrantes das famílias paterna e materna, suas relações familiares, ocupações, atividades e características pessoais ao longo das gerações.

O projeto foi desenvolvido como uma atividade prática de HTML e CSS, com o objetivo de representar visualmente a estrutura familiar de forma organizada e criativa.

📚 Aprendizados

Durante o desenvolvimento, pratiquei a estruturação de páginas com HTML, a estilização com CSS e a organização de informações em elementos visuais.
